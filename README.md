# 3D 点云偏差矢量分析系统 · 使用说明

面向三坐标 / 车身测量场景的网页端可视化工具：导入 Excel 测点数据后，在三维视图中按车身坐标系（BCS）显示各测点的 X / Y / Z 偏差矢量、超差状态与数值，并可叠加 GLB 参考模型进行比对。

- 线上地址：https://hfa007.github.io/pointcloud-web/
- 运行方式：纯前端页面，无需安装；使用 Chrome / Edge 等现代浏览器打开即可，需浏览器支持 WebGL。

---

## 一、界面布局

打开页面后分为左右两栏：

- **左侧控制面板**：数据导入、模型导入、公差设置、筛选显示、显示控制、超差统计与清单。
- **右侧 3D 视口**：点云、偏差矢量、理论点与参考模型的三维展示区。
- **左下角图例**：说明 X / Y / Z 轴颜色、理论点标记含义。
- **左上角提示条**：当前鼠标与快捷键操作说明。
- **右上角「🎯 重置视图」**：恢复默认前视角度。

### 坐标系与颜色约定（车身坐标系 BCS）

| 颜色 | 方向 | 含义 |
|---|---|---|
| 🔴 红 | X 向 | 纵向（前 → 后）/ X 方向偏差矢量 |
| 🟢 绿 | Y 向 | 横向（左 → 右）/ Y 方向偏差矢量 |
| 🔵 蓝 | Z 向 | 竖直（下 → 上）/ Z 方向偏差矢量 |
| ⚪ 灰点 | 理论点位 | 测点名义坐标位置 |

默认视角：**Z 轴正方向向上，X 轴正方向朝左，Y 轴正方向指向屏幕外（正前视图）**。

## 二、快速开始

### 1. 查看内置示例
页面首次打开会自动载入内置示例数据并完成偏差分析，可直接在视口中旋转、缩放查看。

### 2. 导入自己的 Excel 数据
1. 在左侧「**数据导入**」区域，点击上传框，或将 `.xls / .xlsx` 文件拖入。
2. 系统自动识别表头与各列，解析每个测点的名义坐标、实测坐标与公差。
3. 解析成功后：状态栏显示测点数量，视口自动重新分析并渲染超差矢量；下方统计与清单同步更新。
4. 若提示"未能识别到有效测点数据"，请对照第五节的格式要求检查表格。

### 3. 叠加参考模型（可选）
1. 在「**参考模型导入**」区域，点击上传框或拖入 `.glb` 文件。
2. 模型以半透明方式叠加在点云原位，可在控制区调整显隐与透明度。
3. 不需要时点击「移除模型」即可清除。

### 4. 定位超差点
在「超差点清单」中查看按偏差大小排序的测点；点击 / 对照名称可在视口中找到对应矢量。配合筛选条件可只看指定类型或仅看超差点。

## 三、左侧面板功能说明

### 1. 数据导入
- 支持 `.xls`、`.xlsx`；自动识别检测报告格式的表头。
- 上传后自动解析并重新分析；重复导入会覆盖当前数据。

### 2. 参考模型导入
- **格式**：仅支持 `.glb`（二进制单文件，推荐由 CAD / PolyWorks 导出）。
- **显示模型**：勾选 / 取消勾选控制模型显隐。
- **模型透明度**：滑块 5%–100%，默认 35%；模型保留原色、半透明叠加。
- **移除模型**：从场景中清除当前模型并释放资源。
- 载入成功后会显示网格数量与估算三角面数。
- 模型按文件原始坐标原位叠加，不自动对齐到点云中心。

### 3. 数据状态
显示当前数据来源（内置示例 / 已导入文件）与测点数量。

### 4. 公差设置
- **使用各点自带公差**：勾选时，每个测点使用 Excel 中读取到的 X / Y / Z 公差；关闭后使用下方统一公差。
- **统一公差（±mm）**：关闭上方选项后生效，可分别设置 X / Y / Z，默认均为 0.7。
- 点击「**重新分析**」按当前公差与选项重新计算超差状态。

> 公差判定：某轴向偏差的绝对值 **大于** 该轴向公差即判定为该轴超差；任一轴超差，该测点即计入超差点。

### 5. 筛选显示
按条件在视口与统计中只显示满足条件的测点：

- **名称关键字**：模糊匹配，不区分大小写（如输入 `圆`、`98H`、`矩形`）。
- **特征类型**：全部 / 圆孔·圆特征 / 矩形·方孔 / 槽 / H 形面 / 基准 / 纯数字编号。
- **合格状态**：全部 / 仅超差 / 仅合格。
- **清除筛选条件**：一键重置三项筛选。
- 筛选后统计区标题会显示「筛选后数量 / 总数」。

### 6. 显示控制
- **X / Y / Z 偏差矢量**：分别控制三个方向的箭头是否显示。
- **理论点标记**：是否显示测点名义坐标灰点。
- **坐标轴 / 网格**：是否显示参考坐标轴与地面网格。
- **点名称标签**：是否显示测点名称（字号 48）。
- **偏差数值标签**：是否在矢量末端显示各轴偏差数值。
- **矢量放大倍数**：滑块 20–500，默认 120；偏差较小看不清时可调大，避免箭头互相遮挡时调小。

### 7. 超差统计
- **总测点数**：当前参与统计的点数（筛选后会显示「筛选后 / 总数」）。
- **超差点数**：存在至少一个轴向超差的测点数量。
- **不合格率**：超差点数占当前点数的百分比。
- **最大偏差**：偏差最大的测点名称及其偏差值（mm）。

### 8. 超差点清单
- 按最大偏差从大到小排序。
- 每条显示测点名称、最大偏差值，以及超差轴向的偏差（X / Y / Z，带正负号）与公差。
- 偏差越大，标签颜色越偏红。

## 四、3D 视口操作

| 操作 | 功能 |
|---|---|
| **左键拖拽** | 旋转视角 |
| **滚轮** | 缩放视图 |
| **右键拖拽** | 平移视图 |
| **右键单击**（不拖动） | 在正前视 / 后视之间切换，即翻转 Y 轴朝向 |
| **键盘 Y / y** | 整体视图绕 Z 轴水平旋转 180° |
| **🎯 重置视图** | 清除平移偏移，恢复默认前视角 |

补充说明：
- 在输入框 / 数值框中打字时按 Y 不会触发视图翻转，避免误触。
- 缩放在一定范围内自适应限制；平移与旋转均可 360° 自由操作。

## 五、Excel 数据格式要求

### 列识别规则
系统自动在表头中识别以下列（找不到时按常见位置兜底：名称、轴、名义、测量、公差）：

| 含义 | 可识别的表头关键字 |
|---|---|
| 测点名称 | 名称 / 点名 / 点号 / 特征名 |
| 轴向 | X、Y、Z（控制 / 轴 / 方向） |
| 名义（理论）坐标 | 名义 / 理论 / NOMINAL |
| 实测（测量）坐标 | 测量 / 实测 / MEASURED |
| 公差 | 公差 / TOL / 偏差带 |

- 每个测点通常占三行，轴向分别为 X、Y、Z；三个轴向数据齐全才会被保留。
- 公差支持 `±0.7`、`0.7`、`+/-0.7` 等写法；未读到时按默认公差处理。

### 缺省公差规则
- 未单独识别到公差时，默认 ±0.7。
- 形如 `98H1` 的 H 形面、以及名称含「圆 / 矩形 / 槽」的特征，缺省公差按 ±0.5 处理。
- 勾选「使用各点自带公差」时，以上缺省规则仅作用于表格未给出公差的测点。

### 偏差计算
- 各轴偏差 = 实测坐标 − 名义坐标（dx = mx − nx，dy = my − ny，dz = mz − nz）。
- 超差判定：`|dx| > 公差X`、`|dy| > 公差Y`、`|dz| > 公差Z`。

## 六、参考模型（GLB）说明

- **支持格式**：仅 `.glb`；不支持 OBJ / STL / FBX / STEP 等格式。
- **导入方式**：文件在浏览器本地解析，不上传到服务器。
- **显示效果**：半透明、保留原色、双面显示、关闭深度写入以避免透明面互相遮挡。
- **坐标对齐**：模型按自身原始坐标叠加；如需与点云对齐，应在导出 GLB 前于 CAD / 测量软件中统一坐标系。

## 七、项目文件结构

线上仓库为便于部署，将页面与脚本拆分为以下文件：

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架、样式与控件布局 |

## 八、常见问题（FAQ）

**Q：打开页面还是旧界面？**
A：GitHub Pages 可能有缓存，按 `Ctrl + F5`（Mac：`Cmd + Shift + R`）强制刷新。

**Q：视口空白 / 提示无法创建 WebGL 上下文？**
A：当前浏览器或环境禁用了 GPU / WebGL。请更换 Chrome / Edge 等支持 WebGL 的浏览器，并确认已开启硬件加速。

**Q：导入 Excel 后没有测点？**
A：检查表头是否包含可识别的名称列与 X / Y / Z 轴向列；名义与测量坐标需为数字；每个测点三个轴向数据需齐全。

**Q：模型不显示？**
A：确认文件是 `.glb`（而非 `.gltf` / `.obj` / `.stl`）；检查「显示模型」是否勾选、透明度是否被调到过低；模型可能与点云不在同一坐标范围，可缩放 / 平移查看。

**Q：箭头太短看不清 / 太长互相遮挡？**
A：调整「矢量放大倍数」滑块；也可在显示控制中关闭暂不关注的轴向矢量。

**Q：如何只看某一类特征或只看超差点？**
A：在「筛选显示」中按名称关键字、特征类型或合格状态组合筛选，统计与清单会同步更新。
